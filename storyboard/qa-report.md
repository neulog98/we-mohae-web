## 수동/환경 의존 QA 보류 항목

아래 항목은 브라우저 권한, 클립보드, 다중 계정 동시 세션, 또는 추가 업무 규칙 검증이 필요해 이번 자동 QA에서는 보류했다.

1. 신규 회원가입 후 온보딩에서 커플 모드 선택, 초대코드 생성 확인
2. 신규 회원가입 후 예비부부 모드 선택, 하단 예산관리 탭 노출 확인
3. 초대코드 복사/재생성 후 기존 코드 실패와 새 코드 성공 확인
4. 두 번째 계정의 초대코드 합류와 양쪽 파트너 정보 표시 확인
5. 모드 변경 후 기존 예산 데이터 보존 확인
6. 비밀번호 변경 성공/실패 케이스
7. 알림 권한 거부/허용과 FCM 토큰 저장 권한
8. 커플 연결 해제 후 새 커플 공간과 기존 공유 데이터 격리

## QA 소견

Firebase Emulator 기반 seed를 추가해 인증 이후 주요 화면까지 실제 브라우저에서 검증했다. 이번 자동 QA는 비인증 보호, 로그인 계열 validation, 예비부부/커플 모드 분기, 파트너 표시, 캘린더 필터와 일정 수정/삭제, 예산 금액 validation, 데스크톱 테이블, 검색/상태 필터, 저장 반영을 커버한다. 다음 단계는 초대코드 교환, 모드 변경, 연결 해제, 알림 권한처럼 브라우저 권한 또는 다중 사용자 상태 전이가 필요한 시나리오를 별도 fixture로 확장하는 것이다.
